# claudy/

What Claudio shares with [Claudy](https://github.com/Endikk/Claudy), its macOS sibling, pulled by
`Scripts/sync-claudy.ps1`. **Do not edit by hand**: change it in Claudy, then sync.

| Path | What it holds |
|---|---|
| `Design/` | Colours, metrics, shadow, springs (W3C Design Tokens) and the pixel mascot |
| `Fixtures/` | Anthropic's answers and the reading both apps must take from them |
| `REF` | The Claudy commit these files come from |
